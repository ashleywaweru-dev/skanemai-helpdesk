# SkanemAI Helpdesk 🤖

## Project Overview

SkanemAI Helpdesk is an academic AI-assisted helpdesk project designed to help organizations manage technical support requests more efficiently.

The project focuses on classifying support tickets, identifying their urgency, and assigning them to the appropriate support team.

## Key Features

- Technical support ticket management
-  AI-assisted ticket classification
- Urgency identification
- Ticket assignment
-  Helpdesk dashboard
-  Multilingual ticket handling

## Project Dataset

The project was designed around a dataset of approximately 200 support tickets containing 8 attributes.

The tickets included multiple languages, allowing the system concept to explore multilingual technical support classification.
